# Le’memo 利用規約

# Le’memo 利用規約

**施行日：2026年10月1日**  
**最終更新日：2026年10月1日**

本利用規約（以下「本規約」といいます。）は、毛利祐介（以下「運営者」といいます。）が提供するアプリケーション「Le’memo」（以下「本サービス」といいます。）の利用条件を定めるものです。

本サービスを利用するユーザー（以下「ユーザー」といいます。）は、本規約に同意のうえ、本サービスを利用するものとします。

## 第1条（本サービス）

1. 本サービスは、ユーザーが人物に関する情報、会話や出来事の記録、お出かけ、訪問先、支出、贈答品、写真、メモその他の情報を整理・管理するためのアプリケーションです。
2. 本サービスで提供される機能は、アプリのバージョン、利用プラン、利用端末、OS、地域その他の条件により異なる場合があります。
3. 運営者は、ユーザーへの事前通知または本サービス内での告知等により、本サービスの内容を追加、変更または終了することがあります。

## 第2条（利用資格）

1. ユーザーは、自らの責任において本サービスを利用するものとします。
2. 未成年者が本サービスを利用する場合は、必要に応じて親権者その他の法定代理人の同意を得るものとします。
3. ユーザーは、法令、第三者の権利および本規約に違反する目的で本サービスを利用してはなりません。

## 第3条（登録情報および入力情報）

1. ユーザーは、本サービスに入力、保存、読み込みまたは連携する情報について、自ら適法に取得し、利用する権限を有するものとします。
2. 第三者の氏名、写真、連絡先、会話内容、行動履歴、支出情報その他の個人に関する情報を登録する場合、ユーザーは適用法令および当該第三者の権利を侵害しない方法で取り扱うものとします。
3. 運営者は、ユーザーが入力した情報の正確性、適法性、完全性、最新性を保証しません。

## 第4条（禁止事項）

ユーザーは、以下の行為をしてはなりません。

1. 法令または公序良俗に違反する行為
2. 他人のプライバシー、肖像権、著作権、名誉その他の権利または利益を侵害する行為
3. 不正に取得した情報を登録、保存、共有または利用する行為
4. 嫌がらせ、監視、脅迫、詐欺、ストーキングその他の不正目的で本サービスを利用する行為
5. 本サービスまたは関連システムへ過度な負荷を与える行為
6. 不正アクセス、リバースエンジニアリングその他の方法により本サービスの安全性を損なう行為
7. 本サービスの正常な運営を妨げる行為
8. その他、運営者が合理的な理由に基づき不適切と判断する行為

## 第5条（利用プラン）

1. 本サービスでは、次の利用プランを提供する場合があります。
   - Base
   - Standard
   - Executive
2. Baseは無料の基本プランです。
3. StandardおよびExecutiveは有料プランとして提供される場合があります。
4. Executiveは、原則としてStandardの対象機能を含む上位プランとして提供されます。
5. 各プランで利用できる機能の具体的内容は、本サービス内または購入画面に表示します。
6. 運営者は、プラン名、機能構成、料金その他の内容を変更することがあります。

## 第6条（有料プランおよび自動更新）

1. StandardおよびExecutiveその他の有料プランは、App StoreまたはGoogle Play等を通じた自動更新サブスクリプションとして提供される場合があります。
2. 契約期間、料金、更新価格、無料トライアル、更新条件その他の重要事項は、購入画面に表示します。
3. サブスクリプションは、ユーザーが各プラットフォームで解約しない限り、各契約期間の終了時に自動更新されます。
4. アプリを削除またはアンインストールしても、サブスクリプションは自動的には解約されません。
5. 解約、プラン変更、請求管理その他の手続は、原則としてAppleまたはGoogle等が提供するアカウント管理機能から行うものとします。

## 第7条（無料トライアル）

1. 運営者は、有料プランについて無料トライアルを提供する場合があります。
2. 無料トライアルの期間、適用条件および終了後の料金は、購入画面に表示します。
3. StandardとExecutiveについて、それぞれ独立した無料トライアルが提供される場合があります。
4. 無料トライアル期間終了前に解約されない場合、各プラットフォームの条件に従って有料契約へ自動移行することがあります。

## 第8条（料金および価格改定）

1. 有料プランの料金は、購入時にApp Store、Google Playその他の購入画面に表示される価格を適用します。
2. 日本向けの初期価格として、次の価格を予定しています。
   - Standard：月額380円 / 年額3,800円
   - Executive：月額980円 / 年額9,800円
3. 実際の販売価格は、地域、通貨、税、ストアの価格設定その他の条件により異なる場合があります。
4. 運営者は、新規購入者向けの料金を変更することがあります。既存契約者への価格変更は、各プラットフォームの規則および適用法令に従います。

## 第9条（キャンペーン、アンバサダー、テスター等）

1. 運営者は、アンバサダー、テスター、キャンペーン参加者その他の特定ユーザーに対して、無償利用、割引、クーポン、期間限定アクセスその他の特典を提供することがあります。
2. 特典の内容、利用条件、期間、対象プランその他の条件は、個別に定めます。
3. アンバサダーまたはテスター向けの利用資格は、通常の有料サブスクリプションとは別の方法で付与される場合があります。
4. 特典は、譲渡、転売その他運営者が認めない方法で利用してはなりません。

1. 対応するプラットフォームにおいて、ユーザーは購入済みの利用資格を復元できる場合があります。
2. 復元可能な範囲は、Apple、Google、RevenueCatその他のプラットフォームまたはサービスの仕様に従います。

## 第11条（返金）

1. App StoreまたはGoogle Playを通じた購入に関する返金は、原則として各プラットフォームの規約および返金ポリシーに従います。

2. ユーザーは、自らの責任において必要なバックアップを行うものとします。

1. 本サービスは、将来、AIによる情報整理、要約、音声解析、OCR、会話データの構造化その他の機能を提供する場合があります。

3. ユーザーは、AIによる出力を自ら確認したうえで利用するものとします。
4. AI機能の利用に伴って外部サービスへデータを送信する場合は、当該機能の提供開始時にプライバシーポリシーその他の方法で必要な事項を明示します。
